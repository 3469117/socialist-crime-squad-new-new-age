# Socialist Crime Squad: New New Age

**Socialist Crime Squad: New New Age** (SCS) is a modern political conversion of
**Liberal Crime Squad: New Age**, reworking the game's ideological conflict around
Socialists, Liberals, Reactionaries, and Fascists in a heightened contemporary
United States.

**Current version:** `v0.1.4`

> SCS is in active early development. Expect incomplete conversions, inherited
> LCS terminology, balance issues, bugs, and substantial changes between versions.

## About

SCS preserves the core structure and satirical strategy gameplay of Liberal Crime
Squad while rebuilding its political setting, terminology, issues, media environment,
institutions, and eventually several major gameplay systems.

The current ideological spectrum is:

**Fascist → Reactionary → Liberal → Socialist → Revolutionary Socialist**

The player's organization is the **Socialist Crime Squad (SCS)**.

Its principal extremist rival is the **Fascist Crime Squad (FCS)**.

The Liberal center remains a distinct political force rather than being folded into
either extreme.

## Development

The current release represents the first working SCS baseline.

Implemented so far includes:

- Socialist / Liberal / Reactionary / Fascist political framing
- Socialist Crime Squad and Fascist Crime Squad terminology
- Reworked political issue and law descriptions
- Updated political starting conditions
- Updated media terminology
- Revised title, credits, statistics, and presentation
- Initial 2026-era setting conversion
- Preservation of much of the original game's underlying mechanics and save structure

This is not intended to remain a simple terminology swap.

Planned development includes:

- Labor organizing
- Unions and strikes
- Class and economic position
- Tenant organizing
- Mutual aid
- Worker ownership
- Modern social and algorithmic media
- Contemporary occupations and locations
- Expanded political and electoral systems
- Additional 2020s-era issues and institutions

See [SCENARIO.md](SCENARIO.md) for the current design framework and
[PHASE_2_ROADMAP.md](PHASE_2_ROADMAP.md) for planned development.
